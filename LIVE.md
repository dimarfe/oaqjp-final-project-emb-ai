# Mi Mundo Mágico

Aplicación web pública:

[Abre Mi Mundo Mágico](https://dimarfe.github.io/oaqjp-final-project-emb-ai/)

La aplicación guarda una copia local en el dispositivo y envía voluntariamente las fichas a su backend de Supabase cuando se pulsa **Guardar**.

## Acceso del administrador

La sección **Resultados** solo aparece cuando se abre la aplicación mediante el enlace privado de administración. Ese enlace no debe compartirse con las personas que rellenan el formulario.
