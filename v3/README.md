# Mi mundo Mágico v3

Aplicación web familiar colaborativa para crear un único universo compartido.

## Funciones principales

- Una sola versión canónica: todas las personas con acceso modifican el mismo mundo.
- Guardado automático y sincronización entre dispositivos.
- Acceso mediante contraseña familiar.
- Personajes representados mediante retratos extraídos de la ilustración de referencia.
- Fichas de personajes, transformaciones, evoluciones, lugares y aventuras.
- Creador de escenas original con personajes y elementos arrastrables.
- Estudio para libros, ilustraciones, vídeos animados y hojas de personaje.
- Preparación de encargos para continuar en la sesión de ChatGPT del usuario.
- Biblioteca compartida y aplicación instalable en iPad.

La versión pública se sirve desde `/v2/` en GitHub Pages.
