# Prueba visual 3D — estudio para Elendil

Comparativa interactiva entre el avatar del prototipo original y un busto detallado experimental. No es un juego, no es Unreal Engine y no acredita el parecido definitivo con la ilustración de Elendil. No se debe contratar un servidor gráfico basándose únicamente en esta prueba.

## Funciones comprobables
Giro mediante ratón o gesto táctil, zoom, tres encuadres, tres iluminaciones, comparativa antes/después, modo de malla, marcas eléctricas y captura del visor.

## Límites
Rostro provisional basado en una cabeza escaneada de otra persona. Ojos cerrados, sin animación facial ni cuerpo completo. No hay servidor GPU, multiplayer, Supabase o uso de la API de OpenAI. No se ha modificado Mi mundo Mágico v2 ni el juego publicado.
