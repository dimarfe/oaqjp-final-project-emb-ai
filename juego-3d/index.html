Controles

Móvil: mueve con la palanca izquierda; desliza sobre el mundo para mirar. Toca un retrato para cambiar de guardián.

Ordenador: WASD o flechas, ratón arrastrado para mirar, rueda para acercar, Espacio para saltar, Shift para correr, F para magia, E para interactuar, R para evolucionar, M para mapa y P para foto.

El progreso se guarda automáticamente en este navegador. Exporta una partida para llevarla a otro dispositivo.

Juego independiente de Mi mundo Mágico v2. No consulta ni modifica sus datos. Modelos 3D procedurales; no es una reproducción fotográfica de los rostros.
